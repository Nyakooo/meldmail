MeldMail 的首个正式版本。它把多个邮箱汇集到一个可自托管的工作台，并允许每个邮箱独立选择网络连接方式。

## 每个邮箱独立配置代理

- Gmail 可以走 SOCKS5，QQ 邮箱可以直连，工作邮箱也可以使用另一条 HTTP(S) CONNECT 代理。新邮箱默认直连。
- 多个邮箱需要同一条线路时，可以配置共用代理，再让需要它的邮箱单独启用。Linux 部署可用 `MELDMAIL_HOST_PROXY_PORT` 接入宿主机的 HTTP 或混合代理。

## 阅读、收发与清理邮件

- 统一收件箱支持搜索、未读筛选和星标。关闭浏览器后，后台 IMAP 同步仍会继续。打开页面时会收到实时更新。
- 支持撰写、回复、转发和流式下载附件。邮件正文中的 HTTP(S) 链接会在新标签页打开。浅色主题会补足链接文字的对比度，深色主题可切回发件人的原始配色。
- 归档和废纸篓中的邮件可以移回收件箱。废纸篓支持彻底删除单封邮件，也能按邮箱清空。清空会永久删除该邮箱服务端废纸篓里的邮件，包括尚未同步到本地的邮件。

## MCP 访问与发信审批

- 可为客户端创建只读或读写令牌。启用发信审批后，可以先在网页里核对收件人、主题和正文，再批准或拒绝发信。
- 令牌撤销后立即失效。永久删除已撤销的令牌会一并清理关联审批记录，审计日志会保留。

## 部署与维护

Docker 镜像支持 `linux/amd64` 和 `linux/arm64`。要固定到本版本，可在部署目录的 `.env` 中设置：

```dotenv
MELDMAIL_IMAGE=ghcr.io/nyakooo/meldmail:v0.1.0
```

然后运行 `./deploy.sh`。已有部署请保留原来的 `MELDMAIL_MASTER_KEY` 和数据目录。诊断日志可在网页设置中查看，支持按邮箱和级别筛选。
